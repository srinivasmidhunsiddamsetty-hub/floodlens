# Map label glyphs

Signed-distance-field glyph ranges for **Roboto Regular**, **Roboto Medium** and **Roboto Italic**, used by MapLibre to render basemap labels in the same typeface as the UI.

- Source: [openmaptiles/fonts](https://github.com/openmaptiles/fonts) release v2.0 (`v2.0.zip`); only non-empty ranges were extracted.
- Font: Roboto by Google, licensed under the Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0).
